Uma das primeiras aulas do Gustavo fala sobre a história da Internet e sobre como o WWW é uma das redes que funcionam para tranferencia desses html, por meio do protocolo http.

É possível localizar também vídeos falando sobre como são transferidos os dados em formato de bits pelos cabos e como as rotas de saltos são criadas para esses dados caminharem pela internet.

Agora sim ele foca numa parte que nunca entendi, hospedagem e domínio.

Domínio:
Nome que identifica meu site. Esse nome é pago e você paga um aluguel pelo nome, seja anualmente ou mensalmente. Existe um negócio chamado TLD que temos que escolher o tipo.
TLD:
O ".com" numa URL é um exemplo de TLD. Existem dois tipos de TLD's:
GTLD:
O "G" é de genérico, e tem padrões como ".store" para lojas e ".gov" para sites governamentais.
CCTLD:
O "CC" é country code(código de país), como por exemplo ".br" ou ".us".
Hospegem:
Lugar que guarda meu site. Esse local também é alugado. Você escolhe o espaço, a memória e os recursos suportados(suporta banco de dados, roda python no backend e etc.).
Linguagens que veremos:
HTML:
Linguagem de marcação, onde nosso foco será o conteúdo da página.
CSS:
Linguagem de estilização, onde tentamos deixar bonito.
JavaScript
Linguagem de programação, onde vamos interagir com as ações do usuário.
